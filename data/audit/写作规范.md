# 国考逻辑填空学习数据 · 写作规范（所有生成批次必须遵守）

## 零、总原则（质量红线，违反即返工）

1. **准确性优先**：只写有把握的内容。释义、搭配、辨析须符合权威辞书（《现代汉语词典》《现代汉语规范词典》等）的规范标准；把握不准的词，不要写。
2. **真实性优先**：严禁编造或使用无可靠来源的表述，如"国考高频""历年考过×次""必考""大纲词汇""官方推荐"等，一律禁止出现。
3. **严禁抄袭**：例句必须原创自造，不得照抄词典例句、真题原文或网络例句；练习题须自行编写，禁止使用历年真题原题。
4. **不凑数**：不得为凑数量收录生僻、罕用、不适合考试语境的词。
5. **错误即删**：写作中发现已写条目有错，修正或删除后重写，不把错误留在文中。
6. 全部使用简体中文（文件名、字段名除外）。

- 字符串内不要出现换行符（`\n`）。

## 一、成语卡（cards_idioms_*.jsonl）

每行一个 JSON 对象，字段固定如下（不得增减字段，不得改字段名）：

```json
{"word":"望其项背","definition":"能够望见别人的颈项和后背，比喻赶得上或比得上（多用于否定式）。","context":"多用于否定句，表示差距悬殊、赶不上。","collocations":["难以望其项背","不能望其项背"],"confusing_words":[{"word":"望尘莫及","difference":"望尘莫及指远远落后、追赶不上；望其项背强调能够赶上，且多用于否定式，二者语义方向相反。"}],"example":"他在短跑项目上的天赋，让同批队员难以望其项背。","misuse":"常见误用为肯定式表达比不上，如令人望其项背；要表达比不过应说难以望其项背或改用望尘莫及。","difficulty":"medium","tags":["否定式","易混"]}
```

字段要求：
- `word`：纯汉字成语，无标点、无拼音、无空格。
- `definition`：20–60 字，按辞书规范的释义写法（先本义或直解，后比喻义）；不要写成造句或口语解释。
- `context`：15–40 字，说明适用语境（如"多用于否定式""含贬义，用于批评指责""褒义，用于赞扬"）。
- `collocations`：1–3 个**真实存在**的常见搭配（如"难以望其项背"）；不要生造搭配。
- `confusing_words`：0–2 组易混词；每组 `difference` 不少于 20 字，必须说明**实际区别**（语义侧重、范围大小、感情色彩、使用对象、搭配限制、语体差异中的至少一项）。禁止"更高级""更正式""更书面"这类空泛描述而不加说明。没有合适的易混词时填 `[]`。
- `example`：20–45 字原创例句，语境自然、贴合当代使用。
- `misuse`：15–40 字，指出该词最常见的误用方式及正确用法。实在没有常见误用时，可写使用注意点（如"使用时多与否定词搭配"）。
- `difficulty`：`easy`（常见且易理解）/ `medium`（常见但有辨析点）/ `hard`（辨析难度较大）三选一。
- `tags`：1–3 个，从以下词表选：褒义、贬义、中性、否定式、易混、书面语、口语、程度重、程度轻、对象特定、古今异义。可组合，如 `["贬义","易混"]`。

常见错误（禁止）：
- ❌ 释义写成文学化描述："形容一种特别高远的境界"（不准确、不具体）
- ❌ 搭配生造："风雨同舟共济"（拼凑）
- ❌ 辨析空话："这个成语更高级"（无实际信息）
- ❌ 例句抄词典："其才力不足望其项背者，辄逡巡不敢复笔"（抄袭古书书证）

## 二、实词卡（cards_words_*.jsonl）

实词卡 = **单个实词**（动词 / 形容词 / 名词 / 副词）的用法卡，以国考逻辑填空语境中易混、易错的常用实词为重点。

```json
{"word":"遏制","definition":"制止，控制（使不再继续发展）；侧重于控制住、压下去。","context":"多用于抽象事物，如势头、势头、不良趋势等。","collocations":["遏制势头","遏制蔓延","有效遏制"],"confusing_words":[{"word":"遏止","difference":"遏止侧重使停止，程度更重，多用于行为、现象；遏制侧重控制住不使加剧，对象多为趋势、势头。"}],"example":"多项治理措施同步推进，污染扩散的势头得到有效遏制。","misuse":"常与遏止混用；表达使某现象彻底停止宜用遏止，表达控制势头不再加剧宜用遏制。","difficulty":"medium","tags":["易混","书面语"]}
```

字段要求同上（word 为单个词语，2–4 字为主；不要收单字词）。`confusing_words` 至少给出该词最易混淆的 1 个词并说明区别。`context` 要写清对象类型与语体。

常见错误（禁止）：
- ❌ 收录生僻词、专业术语词（如"谵妄"）
- ❌ 释义与词性不符（把动词当形容词解释）
- ❌ 辨析空话："遏止比遏制程度深"——必须说清深在哪、用在哪

## 三、近义词辨析（comparisons_*.jsonl）

每行一个 JSON 对象（1 组 = 2 个词）：

```json
{"words":["遏制","遏止"],"similarity":"都表示阻止、不让继续，含制止之义。","key_difference":"遏制侧重控制住不让加剧，是过程性控制；遏止侧重使彻底停止，是结果性终止，程度更重。","usage_difference":"①语义范围：遏制多用于势头、趋势、蔓延等可量化的抽象态势；遏止多用于行为、现象本身。②搭配限制：常见有效遏制、遏制势头；遏止乱象、遏止谣言。③语体：二者均为书面语，公文语境均常见，但遏止更强调决心与力度。","examples":["相关部门出台多项措施，有效遏制了违规行为的蔓延势头。","当地迅速开展专项整治，一举遏止了违规收费乱象。"],"source_note":"依据权威辞书释义及现代汉语规范用法辨析"}
```

字段要求：
- `words`：恰好 2 个真实存在的词语（成语或实词）。
- `similarity`：20–40 字，写清共同的核心语义。
- `key_difference`：30–70 字，1 句说清最重要的语义区别。
- `usage_difference`：80–160 字，从**语义范围 / 感情色彩 / 使用对象 / 搭配限制 / 语体差异**中至少覆盖 3 个维度展开，用①②③分条。禁止空话（"更正式""更高级"而不加说明 = 返工）。
- `examples`：2 句原创例句，分别使用两个词，语境自然。
- `source_note`：固定写法"依据权威辞书释义及现代汉语规范用法辨析"。

## 四、国考逻辑填空训练题（questions_*.jsonl）

每行一个 JSON 对象：

```json
{"question":"古籍修复是一项极其讲究的工作，修复师下笔之前往往要________，反复比对纸张的纹理与色泽，稍有疏忽便可能对文物造成不可逆的损伤。填入画横线部分最恰当的一项是：","options":{"A":"深思熟虑","B":"处心积虑","C":"瞻前顾后","D":"谨小慎微"},"answer":"D","analysis":"A项，深思熟虑指深入细致地考虑，侧重考虑得深入，而文段强调修复师操作时的谨慎态度，与谨慎这一核心不匹配；B项，处心积虑指长期谋划坏主意，含贬义，感情色彩不符；C项，瞻前顾后形容顾虑太多、犹豫不决，含贬义，与修复师的专业严谨不符；D项，谨小慎微指对细小的事情也谨慎对待，恰好对应反复比对、不敢疏忽的语境，符合文意。故本题选D。","knowledge_point":"成语的感情色彩与语境搭配（谨慎态度类成语辨析）","related_words":["谨小慎微","深思熟虑","处心积虑"]}
```

字段要求：
- `question`：自编文段 50–130 字，留 1–2 空，用 `________`（8 个下划线）表示空；句末固定加"填入画横线部分最恰当的一项是："。
- `options`：4 个选项，A–D 均为真实存在的词语（互为近义或易混词），不得使用编造词。
- `answer`：A/B/C/D 之一。
- `analysis`：必须**逐项分析**，格式为"A项，……；B项，……；C项，……；D项，……。故本题选X。"每个错误项要说明**具体排除理由**（语义不符 / 搭配不当 / 感情色彩不符 / 语体不符 / 逻辑矛盾），不得只写"不恰当""不符合"就完事。最后一句必须是"故本题选{answer}。"。
- `knowledge_point`：15–40 字，概括本题考点。
- `related_words`：2–3 个与本题相关的高频考点词（从题干或选项中选取）。

出题自检（每题写完后必做，不合格就重写）：
1. 把 4 个选项逐个代入空处，检查是否**只有 1 个**能成立；若有 2 个都说得通，换词或改文段，直到唯一。
2. 检查干扰项是否存在**明确且可写出的排除依据**；写不出排除依据的选项，换掉。
3. 检查文段本身无语法错误、无逻辑漏洞。

常见错误（禁止）：
- ❌ 两个选项语义都能成立（有争议题）
- ❌ 干扰项与考点无关（随手凑词）
- ❌ 解析只写答案不写排除理由
- ❌ 照抄真题原题
